CO INVESTMENTS BROILER MANAGER

Contents:
- index.html (main application)
- manifest.json (PWA settings)
- service-worker.js (offline support)
- icon-192.png
- icon-512.png

Deployment:
1. Extract this ZIP.
2. Upload all files to the root of your GitHub repository.
3. Enable GitHub Pages or deploy with Netlify/Vercel.
4. Open the HTTPS website on Android and choose Install App / Add to Home Screen.

Firebase configuration is already included in index.html.
