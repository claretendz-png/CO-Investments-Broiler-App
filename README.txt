CO INVESTMENTS BROILER MANAGER PWA

1. Upload all files in this folder to a HTTPS web host.
2. Open the hosted address in Chrome on Android.
3. Test Sign In / Create User.
4. Chrome menu -> Install app / Add to Home screen.

Important:
- Firebase Authentication and Firestore must remain enabled in the existing Firebase project.
- The current Firestore open testing rule should be replaced with authenticated-user rules before distributing the app.
- PWA service workers require HTTPS (localhost is also allowed for development).
